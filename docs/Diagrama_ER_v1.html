Notas del Diagrama ER

  • Este diagrama muestra las tablas físicas en base de datos.
  • A diferencia del diagrama de clases, aquí las tablas intermedias (proyectos_usuarios y tareas_operarios) se muestran explícitamente para representar las relaciones N:N.
  • Las llaves foráneas (FK) y llaves primarias (PK) se indican junto a las columnas.
  • Las enumeraciones en SQLAlchemy (como UserStatus, ProyectoEstado) se guardan como cadenas de texto (String) en la base de datos.
